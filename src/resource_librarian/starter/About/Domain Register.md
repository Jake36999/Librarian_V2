# Domain Register

Each domain is a field the scout searches for candidates, with the queries it starts from. Empty
until the first topics are accepted; the librarian proposes domains from them.

`Sensitive` = `yes` sends everything found in that domain to a person for review. It is never
promoted automatically, whatever the promotion setting (`SENSITIVITY_REVIEW`).
