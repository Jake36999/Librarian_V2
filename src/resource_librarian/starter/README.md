# {name}

A research library: sources someone has actually read, with the evidence attached, and a record
of what they were used for. Created {created} by the Librarian.

## Where things are

| Folder | Holds |
| --- | --- |
| `Projects/` | one note per project the library serves: its stage, what is fixed, what rules a source out |
| `Sources/` | one note per source, by kind: repositories, papers, datasets, documents, pages, standards, models |
| `Concepts/` | terms and recurring patterns, each built from how several sources use it |
| `Offerings/` | what several sources could do together, for a project or as an insight |
| `Applications/` | what was actually used, what it replaced, and what the library should learn |
| `Inbox/` | drop files here to add them |
| `Indexes/` | browsable indexes, generated: never edit by hand |
| `About/` | this vault's schema and vocabularies: edit these to change what the library may record |

Hidden folders hold machinery, not notes: `.evidence/` is what was fetched, kept exactly as it
arrived; `.librarian/` holds settings, research threads and work in progress, and
`.librarian/derived/` holds the search index, which can always be deleted and rebuilt.
