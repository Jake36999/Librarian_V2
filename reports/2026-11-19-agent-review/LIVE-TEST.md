## Stuck Ledger (Every Newcomer Dead-End & Blocker)

1. **Empty-Catalog Standalone Geo Deadlock (`F-01`):** Running `geographer serve-graphs --create-catalog` leaves the UI permanently frozen on `"Opening project graphs…"` (`0` controls). **Workaround:** Only bypassed by seeding a dummy graph via CLI `init-workspace --yes`.
2. **Broken Inherited Chat Model `lead-m` & Unqualified Clerk (`F-02`):** Every Chat prompt fails `HTTP 404` (`The model 'lead-m' does not exist`), Chat workflows cannot run, and `Process approved sources` silently leaves papers at `partial 0/16` unless the user inspects `"Draft with the clerk"` (`experimental (missing)`) or manually types `Bottom Line` & `What it solves`.
3. **Antigravity Geo MCP Returns Blank Output (`F-04`):** `call_mcp_tool` on all 22 `geo-grapher` tools prints nothing because `"content": []` omits text while stuffing payloads into `"structuredContent"`. **Workaround:** External raw stdio JSON-RPC client (`run_geo_mcp_b2.py`).
4. **Silent `Modes: Ask` Approval Deadlock Between MCP Client & Web UI (`F-03`):** Calling any write Librarian MCP tool (`ingest`, `open_brief`, `create_project`, `desk_pin`) blocks the MCP client until its 180s timeout with zero indication why, while the approval card renders only on the Web UI `Chat` tab with zero badge on `Staging`/`Search`.
5. **Librarian-Launched Geo `Add folder…` Dead-End (`F-05`):** Clicking `Build -> Add folder…` on Librarian-managed `:65417` immediately errors (`--browse-root` missing), and `Compare` 400s on paper-only vaults (`F-16`).
6. **UI `Desk` (`Pin`/`Unpin`) Missing (`F-11`) & Staging Local-Path Add Missing (`F-10`):** Zero `Desk` or `Pin` controls exist in Librarian UI, and `Staging` has no button to queue/ingest a local path when Chat is down.
7. **Geo Scissors (`F-15`) & Docs Search (`App_repo/docs`) Confusion:** Framing/searching a file never surfaces Scissors until box-selecting on canvas, and `Hierarchy` hides documentation until `Documentation` is ticked.

## What I Would Change First to Make This Easier to Use

1. **Fix both cold-start blockers (`F-01`, `F-02`):** Replace Geo's early return when `graphs.length === 0` with an empty-catalog onboarding state pointing directly at `Build -> Add folder…`, and validate Librarian's `Lead` / `Clerk` routes at boot instead of letting a newcomer hit `lead-m` HTTP 404 and unscreened clerk traps.
2. **Surface MCP/Agent `Ask` approvals globally across Librarian (`F-03`) and populate `content` in Geo MCP (`F-04`):** Put a persistent header badge on Librarian (`Approvals (1)`) visible from Staging/Search so external MCP writes don't silently hang, and serialize JSON into `content` in `geographer serve-graphs` alongside removing phantom parameters (`content_kind`, `direction`) and slow cold search blocking (`F-06`, `F-07`).
3. **Wire Librarian `Search` facets, Staging `"Add source"`, and UI `Desk` (`F-10`, `F-11`, `F-12`):** Bind backend `facets` to clickable filter tiles, add a non-LLM Staging upload/path input, and either expose Desk pinning in the Document Pane or remove dangling workflow references.
4. **Make Geo Scissors & Declared Bridges directly discoverable and traversable (`F-08`, `F-15`):** Show Scissors whenever any file/folder is selected in Hierarchy, Search, or Inspect, and make Gold bridge arcs + `Inspect -> Links` bridge cards clickable to jump straight across linked graphs with an explicit `"unverified"` badge.
5. **Fix layout collisions (`F-13`, `F-14`, `F-18`):** Separate `Reveal nearby detail` from `.scene-edit-help`, stop `Rules configuration` from burying `Legend`, widen/wrap `Inspect` so `Investigate` and IDs don't clip or scroll, and consolidate Librarian's redundant `Settings` / `Models` header buttons.
