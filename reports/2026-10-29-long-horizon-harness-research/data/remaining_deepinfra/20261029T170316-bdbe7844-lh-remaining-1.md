## New design implications (max 3)

1. **Bounded LLM adjudication at checkpoints:** pre-filter candidates deterministically (similarity/rule), then let the LLM make only binary keep/drop decisions with fixed decoding and a conservative default on ambiguity (remaining_04, pp. 5–7, 18–20). This bounds cost and context without asserting semantic correctness.
2. **Provenance metadata on every extracted unit:** store source document and position with each artifact so human checkpoints and audits can trace claims (remaining_02, p. 10; remaining_01 logging/audit recommendation, p. 23).
3. **Treat verification as unsolved:** design explicit recovery/error-detection paths and human review gates rather than relying on LLM self-checks; the review states formal verification for open-ended LLM agents is unavailable (remaining_01, pp. 19–21).

**Assumptions/risks:** All four sources are 2026 publications; only remaining_01 is a review (no primary evidence), and remaining_02/04 evaluate graph tasks, so their metrics do not transfer to text-coordination harnesses.
