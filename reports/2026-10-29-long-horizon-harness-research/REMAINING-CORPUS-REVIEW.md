# Remaining academic papers: screening, extraction, and design implications

Date: 2026-10-29. This pass completes screening of the academic PDFs in `E:\Librarian research` and supports the [harness design specification](../../docs/long-horizon-harness-design.md).

## Coverage and method

The folder contains 51 files, all PDFs. Earlier passes extracted 37 files. This pass inventories and extracts the remaining 14, then sends their full extracted text to four bounded DeepInfra readers. All four new reader responses completed without truncation. Relevant passages were subsequently read locally, with source locations and limitations checked before inclusion below. This is a complete relevance screening and targeted evidence extraction, not a claim to have independently reproduced every experiment or peer-reviewed every paper in full.

One of the remaining PDFs is byte-identical to a previously reviewed KDRAR copy. The folder therefore contains **51 PDF files with 50 distinct SHA-256 hashes**, not necessarily 50 independent studies: related versions such as the ReflectiChain documents still require bibliographic reconciliation.

## Corrections to earlier attribution and transfer claims

1. **LLM-S2KG supplies the Chroma/inhibit→promote passage.** The paper says retrieval and structure *mitigate* errors; the earlier suggestion overstated this as stopping inversions and attributed it to another graph paper.
2. **CoACL supplies Appendix A.3 Conservative Filtering.** `07802-YuJ.pdf` instead contains LLM4NG node generation and learned edge integration. They are different papers and mechanisms.
3. **A typed compiler is not evidence that another LLM call is always worthwhile.** R06's matched-rule result reinforces the need to test the controller's incremental benefit. Its safe default is defined for a simulation, not for a mutation-capable co-work product.
4. **Fixed decoding is not a product determinism guarantee.** Deterministic state replay and authorization can be required; identical hosted model outputs cannot be inferred from a paper's temperature settings.
5. **Hash equality and source identity are distinct from semantic validity.** The duplicate KDRAR copy counts once as evidence. A hash-chain/diff receipt proves only the checks and observation scope actually implemented.
6. **Formal-methods results require their assumptions.** R14's library is useful design inspiration; its correctness results concern its formal language and specified control systems. The harness still needs its own transition and failure fixtures.

## Design changes justified by the new pass

- Add a small catalog of temporal requirements to the acceptance design: no new effects after observed cancellation, no authoritative closure on stale evidence, no execution before admission, and reconciliation before retrying an ambiguous effect. These are design obligations with explicit observation boundaries.
- Treat Manager output as a typed, untrusted proposal. Invalid proposals stop/repair rather than acquiring a permissive default. Re-resolve target and evidence references against current state at preflight and commit.
- Preserve provenance at document and location level, and show unresolved evidence links and missing coverage. Test relation-direction errors separately from source/quote integrity.
- Bound context before model invocation; preserve mandatory constraints or split/park the task. Keep the original source authoritative when generated enrichment is absent or malformed.
- Retain conditional delegation and optional Tier B audit. The new papers do not overcome the local E2′ overhead result or justify default multi-agent review.

These decisions are integrated in the [design specification](../../docs/long-horizon-harness-design.md), which leaves prompt templates, budget sizes, monitor thresholds, ranking, schemas and interface layout open.
