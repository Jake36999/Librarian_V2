## Verdicts on the Six Changes (Section 1)

1. **Phase deadlocks fixed (`BUNDLES`, `MAX_BUNDLE_TOOLS=16`, `suggest` Map brief, `no_progress` guard, `update_plan(fields=...)`) — `keep with fixes`.**
   The core deadlock fix works across 7 of 8 purposes (`explore`, `add_project`, `suggest`, `apply`, `start_pursuit`, `learn`, `add_capability` all walked cleanly on the enforced surface, and real-model tests confirmed `map`, `need`, `judge`, `synthesise`, `check_out`, `apply`, `learn`, and backwards `advance(target='map')` with budget halving). However, `audited` is still deadlocked on `close_session` in every phase (**F-06**), `learn/next`'s gate hint omits `task_add`'s required `note` parameter (**F-12**), `park_session` and backwards `advance` from final phases remain omitted (**F-12**), and `_no_progress_signature` misses alternating refusals, repeated ordinary errors, and repeated `invalid_arguments` (**F-11**).

2. **Clerk / staging / macros (queued Clerk draft reason + reload, `run_macro` checkpoint reuse) — `keep with fixes` (specifically fix `run_macro` reuse before shipping).**
   The Clerk queued-draft reason propagation and UI item reload held cleanly across all refusal states (`no_model_configured`, `host_disabled`, `endpoint_changed`, `route_unqualified`) and fixed stale-revision conflicts after Draft → Approve. In contrast, the `run_macro` checkpoint reuse loop in `agent_runtime.py:947-957` is unsafe as written (**F-02**): it reuses an older `approve` even after a newer `cancel`, allows cross-session/cross-caller approval hijack because `_checkpoint_scope` omits session/requester, permanently wedges repeated legitimate runs on `reused: True`, and races under concurrent execution.

3. **Permission grants (`Broker` `workflow_grant` for `App.start_action` and `batch.STAGE_TOOLS`) — `keep with fixes`.**
   The isolation mechanics and overrides are solid: grants do not leak into `app._extras()`, `Plan` mode / `Deny` / per-tool `Ask` / `ALWAYS_ASK` (`project_edit`, `sandbox_output`) / `_publication_review` taint all override grants, `Broker.set_mode` re-evaluates pending prompts consistently, unaccepted vault pipelines are refused (`PERSON_CONFIRMS`), and the 98-note approved batch ran with 0 prompts and 0 unauthorized acceptances/promotions. The critical gap is informed consent for vault-defined pipelines (**F-03**): clicking an accepted bare pipeline name under `"This vault's pipelines"` silently authorizes arbitrary `contribute` writes (including nested child workflows) in Ask mode without displaying steps or granted tools.

4. **UI (paperclip menu, Pick Mode, Skill Registry, workflow hints, Folder Accepted filter, Staging `"Show 50 more"`, chat model filter, contrast/wrapping, auto-continue) — `keep with fixes`.**
   Most UX refinements held cleanly (`Open original`, dark Settings inputs, `⏻` Escape/outside click, keyboard Tab/Escape focus restoration across all 6 overlays, SSE sync across two tabs, Written de-duplication, quality banner after cleanup, `375×812` Staging kind-tab wrapping, and Chat auto-continue on reopened threads). However, `"Show 50 more"` is completely non-functional due to `MAX_LIMIT = 50` (**F-01**), `ui/smoke.mjs` is broken (**F-07**), Skill Registry has unescaped Markdown/table injection and breaks its own `/review-staging` row (**F-08**), `Modes` clips off-screen at `640×450` / `497×450` and the `768×1024` overlay pane hides `Staging` (**F-13**), Pick Mode leaks state on pane close and corrupts ambiguous/special-char wikilinks (**F-14**), 8 `FLUX-*` image models still leak into chat pickers (**F-15**), and Plan-pane answers skip auto-continue (**F-16**).

5. **Guide (`About the Librarian and how to use it.md`, `About/Tool Reference.md`, first-visit pane auto-open) — `keep with fixes`.**
   `init` cleanly writes the guide and generated `About/Tool Reference.md` (covering all 185 registered tools with clean escaping), preserves pre-existing notes and custom guides when run in a non-empty folder, respects pre-guide libraries (404 leaves pane closed), and respects saved-closed `librarian:pane = "closed"`. However, `apply_adopt` does not generate the Guide, `Tool Reference.md`, or `Rules.md` (**F-16**), `librarian:guide-seen` is origin-scoped rather than library-scoped (**F-16**), and auto-opening the pane broke `ui/smoke.mjs:142` (**F-07**) and exacerbates the `768×1024` full-screen overlay covering `Staging` (**F-13**).

6. **Tooling (`scripts/phase_walk.py` and the 4 new test files) — `keep with fixes`.**
   All 93 targeted tests pass, `scripts/phase_walk.py` exits 0 cleanly (133 probes, 0 unreachable), and `--prepare` reliably parks sessions in target phases for live UI validation. However, `phase_walk.py` only walks 3 of 8 purposes (`explore`, `add_project`, `suggest`) and only checks `Session.missing()`, which is why it missed the `audited` `close_session` deadlock (**F-06**) and the `learn/next` `task_add` hint missing `note` (**F-12**).
