# Content authorship

The owner's permanent policy, 2026-11-14. This note is prepared for `About/Content authorship.md` in each library when its setup/maintenance is approved. It has not been written into a live library at C0.

**owner_created** means our own documents, code and tools: for example an internal architecture plan, original project code or our first-hand reading/test notes. People and agents have full access; this material is ingested completely.

**generated** means Librarian or agent output: drafts, conversions, summaries and use logs. Unaccepted work stays under `.librarian/`. Agents may read it as labelled library work, but never cite a conversion or summary as the original source.

**third_party**, also called **unlicensed** here, means other people's work that we study and cite. We are not its licence distributor and never incorporate it into our repositories or products as though it were ours, whatever its repository licence says. A quoted distributor model card stays third_party even inside our curated note; our observations stay owner_created.

People can read third-party originals freely. For agents, the default route is catalogue → graph of the full conversion → relevant section → bounded verification against original pages. Tiers 1/2 can receive explicit one-off raw-access grants. Tier 3 has bounded targets only. Every route is capped to its declared context window after prompt and output/reasoning reserves.

Internal graph domains contain owner_created and generated material; external domains contain third_party. An unclassifiable object is catalogued, not graphed. A graph without a domain is a defect for owner review, never silently classified.

A third-party read does not forbid more reading. It requires derived content to enter canonical notes through staging and review, preventing source text from becoming an instruction or an unreviewed write.
